# Simple Calculator in C

## Description
This is a simple calculator program written in C.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid operator handling

## Requirements
- GCC Compiler

## Compilation

```bash
gcc calculator.c -o calculator
```

## Run

```bash
./calculator
```

## Example

```
===== SIMPLE CALCULATOR =====
Operations:
+ : Addition
- : Subtraction
* : Multiplication
/ : Division

Enter an operator (+, -, *, /): +

Enter two numbers: 25 15

Result = 40.00
```
